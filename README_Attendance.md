# Attendance Tracker

A modern, efficient alternative to traditional pen-and-paper methods, designed to streamline how presence is recorded for classes, employees, or events.

## 📖 About

By utilizing a web application, users can mark attendance, visualize records, and manage data from any device with an internet connection. This project simplifies attendance management and provides real-time insights into attendance patterns.

**Author:** Divya Bharti

## ✨ Features

- 📝 **Digital Attendance Marking** - Mark attendance quickly and efficiently
- 📊 **Visualize Records** - View attendance data in an organized, visual format
- 🌐 **Web-Based Access** - Access from any device with internet connection
- 💾 **Data Management** - Store and manage attendance records digitally
- 📱 **Responsive Design** - Works seamlessly on desktop and mobile devices
- ⚡ **Real-Time Updates** - Instant attendance tracking and updates

## 🛠️ Technologies Used

- **HTML** (100%) - Frontend structure and interface
- **CSS** - Styling and responsive design
- **JavaScript** - Interactive functionality
- **Git** - Version control

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for initial setup)

### Installation & Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/divyadhankhar2008-byte/Attendance-tracker-.git
   cd Attendance-tracker-
   ```

2. **Open the application**
   ```bash
   # Simply open index.html in your web browser
   # Or use a local server:
   python -m http.server 8000
   # Then navigate to http://localhost:8000
   ```

3. **Start tracking attendance!**
   - Open the application in your browser
   - Follow the on-screen instructions to mark attendance
   - View and manage records through the interface

## 💡 How It Works

1. **Mark Attendance** - Users can quickly mark themselves or others as present
2. **View Records** - Check attendance history and patterns
3. **Generate Reports** - Export or view attendance data
4. **Manage Data** - Edit or update attendance records as needed
